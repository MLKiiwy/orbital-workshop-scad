# LEGO DUPLO bakfiets

> A DUPLO-compatible Dutch cargo bike: frame, cargo box, rain tent and two wheels.

## What

A toy "bakfiets" (Dutch front-loader cargo bike) at DUPLO scale, styled after a Dolly:
long low frame, flared cargo box between the wheels, removable rain tent on top.
LEGO has never made one for DUPLO.

**5 printed pieces from 4 models:**

| Piece | Qty | Notes |
|-------|-----|-------|
| Frame | 1 | Beam, handlebar, rider stand, rear rack, both wheel forks, kickstand, 2x2 deck |
| Cargo box | 1 | Clicks onto the frame deck; has DUPLO studs on its inside floor |
| Rain tent | 1 | Slips over the box collar with a friction fit |
| Wheel | 2 | Identical. Snaps **permanently** into its fork and cannot be taken off again |

```
            ___________
           /  rain tent \\         <- slips over the box collar
          |  ___________ |
          | |           ||
          | |  o     o  ||        <- studs INSIDE the box floor
      o   | |___________||           (a figure or 2x2 brick clicks in)
     _|_  |_|  U     U  |_|       <- sockets UNDER the box floor
    | o | | \\___________/
    |[|]| |      |  |             <- 2x2 studs on the frame deck
   _|___|_______|__|_________
  (O|O)                     (O|O) <- wheel centred in a fork, both sides
   ---    ground clearance    ---
     ^        ^
     |        rider stands here: a stud per foot, a wall between the legs
     rear rack, two studs for luggage
```

**Two real DUPLO interfaces**, both generated by `LEGO.scad` rather than hand-modelled:

- **Frame deck** — a 2x2 DUPLO plate, studs up. The cargo box clicks onto it.
- **Box floor** — a 2x2 DUPLO plate, sockets down onto the deck and **studs up inside the
  box**, so a DUPLO figure or a 2x2 brick clicks in and does not fall out when the bike is
  pushed around.

The box's bottom footprint is exactly the 31.8 mm plate and its walls lean outward going
up, so the interior stays wider than 31.8 mm all the way to the rim — which is what a 2x2
brick needs to drop in.

**The box is deliberately lopsided**, the way a real bakfiets box is:

```
      side view, +X toward the front wheel

      back                              front
       |  <- vertical, tucks up         /
       |     against the handlebar     /  <- leans out 23 mm and
       |                              /      sits over the wheel
       |_____________________________/
       |         2x2 DUPLO plate     |
            ===== frame deck =====          (OOO) front wheel
```

- The **back wall is vertical** so the box can sit as close to the handlebar as possible —
  2 mm of clearance, asserted, counting the tent skirt.
- The **front face leans out** over the front wheel. An assert checks the perpendicular
  distance from the wheel's centre to that sloped face rather than a plain horizontal gap,
  because the box is *meant* to overhang the wheel. Default clearance is 4.6 mm.
- The lean runs the full height of the box so it stays under 45 degrees and needs no
  support; `box_flare_front <= box_flare_h` is asserted.

> LEGO.scad has **no wheel module** — it only exposes `block()`, `uncenter()`, `place()`,
> `stack()` and three height functions. The wheel here is our own geometry.

### Where the rider stands

There is no saddle. The rider **stands and straddles**, the way DUPLO figures ride things:

```
      seen from behind

        [ ]  <- straddle wall, 4 mm thick,
      ( [ ] )   11 mm tall, rounded on top
     (O)[ ](O) <- one DUPLO stud per foot,
      |_____|     16 mm apart (one DUPLO pitch)
```

The two foot studs are exactly one DUPLO pitch apart, so a figure's feet clip straight
onto them, and the wall between fits in the 6.6 mm gap the studs leave.

**Why the bike is 116 mm long.** A DUPLO stud is 9.4 mm wide on a 16 mm pitch, so its
inner edge sits only 3.3 mm from the centreline — inside the 9 mm rear tyre. The foot
studs therefore cannot pass over the tyre at any height below its top, which pins the
rider between the rear wheel and the steering column. There was not 9.4 mm of room there
at the original 104 mm wheelbase, so the wheelbase was stretched and the box and
handlebar moved forward to open the gap. The studs now clear the column by 7.5 mm.

### The rear rack

A rack over the back wheel carrying **two studs in line with the frame**, one DUPLO pitch
apart, so a 2x1 DUPLO piece sits on it:

```
      side view, rear of the bike

        [o]   [o]     <- two studs, 16 mm apart
      |_____________|  <- platform
       \           /
        \  /\     /    <- lightening window
         \/  \   /
          |___|       <- meets the rear fork
           (OOO)         clear of the tyre
```

A side plate in each cheek plane carries it: narrow where it meets the rear fork and
flaring outward going up. That is both what a real rack's stays look like and what keeps
every overhang well under 45 degrees, so the platform can reach out past the fork at each
end with no support. The plates sit clear of the tyre in Y and the platform bridges the
gap between them. They deliberately start above the dropout slot, so cutting the dropout
does not slice them in half.

### The rain tent

The tent is a **mirror of the box**: vertical at the back so it stays clear of the
handlebar, leaning *in* toward the front by exactly as much as the box leans *out*, so
the two read as one shape.

```
      side view, +X toward the front wheel

       |\__________        <- tent leans in
       |           \
       |____________\      <- box rim / tent skirt
       |             \
       |______________\    <- box leans out
```

Printed roof-down that lean becomes an overhang of `atan(box_flare_front / tent_h)` from
vertical — 41.5 degrees at the defaults — which is why `tent_h` has to stay large enough
to keep it under 45. `tent_mirror = 0` gives straight walls instead.

There is a **24 x 18 mm window on each of the four sides**. Two cutting prisms do all
four: each runs clean through the tent, so it cuts the wall at both ends. Printed
roof-down a window's lower edge becomes a bridge across its own width, so the corners are
rounded hard — at the defaults only 12 mm of each window is a flat bridge, and 9.5 mm of
wall is left either side.

### The handlebar

42 mm wide, about the width of the cargo box, on a fan that rises from the steering
column. The fan has a triangular hole through it so it reads as two arms rather than a
plate. The hole's apex points up, so its ceiling is two slopes steeper than 45 degrees
and it needs no support. `bar_hole_w = 0` leaves the fan solid.

## Why

Bakfietsen are how half of the Netherlands moves its children around, including ours.
This is so our daughter can play with the thing she actually rides in. It is an
*inspiration*, not a copy of any particular bike.

Constraints that drove the design:

- **Must be real DUPLO**, not DUPLO-ish: it has to click onto and accept genuine bricks.
- **Toddler-safe.** The wheels are the only pieces small enough to matter, so they are
  `>= 32 mm` (asserted) — below that a wheel fits the 31.7 mm small-parts test cylinder —
  **and** they are captive: once snapped into the fork they cannot be pulled back off.
- **No supports, anywhere.** Every piece is modelled in its print orientation and the
  default `part = "plate"` exports all five already laid out on the bed.
- **A two-wheeler falls over.** Hence the wide tread and the kickstand stub (see below).

## The wheel mount

Each wheel sits in a **symmetric fork**, centred on the bike's midplane with a cheek on
each side. Only the right-hand cheek is cut; the left one stays solid and stops the wheel
tilting under a sideways shove.

**Both forks are slim legs**, not slabs: a low run along the beam, a foot wide enough to
straddle the dropout, and a triangular lightening window (apex up, so its ceiling is two
45-degree slopes and it still needs no support). Keeping the front one low is what lets
the cargo box lean out over the front wheel. `fork_window = false` fills them back in.

The right cheek is a real **bicycle dropout** — an axle hole with a slot running down out
of its bottom edge, and a **neck** between them that is deliberately narrower than the
axle:

```
   right cheek, seen from outside

        ( O )     <- axle hole, 6.3 mm, wheel spins here
         ) (      <- neck, 5.7 mm: axle must be pressed past it
         | |
         | |      <- lead-in slot, 6.3 mm
       --+ +--    <- open at the bottom edge
```

This is what makes a captive wheel possible at all. The peg is longer than the gap between
the cheeks, so the wheel can never be slid in sideways — instead it is fed **up from
below**, with the barb already outboard of the cheek, and the axle pressed past the neck.
After that:

- the **barb** (flat-shelved, 7.6 mm against a 6.3 mm hole) stops it coming out sideways,
- the **neck** stops it dropping back down the slot,
- and the bike's own weight seats the axle in the hole.

## How it goes together

1. For each wheel: hold it between the fork cheeks with the barb outboard of the right
   cheek, push the axle up the slot and press it past the neck — 0.15 mm per side — until
   it snaps into the hole. It then spins on 0.15 mm of radial clearance and is permanent.
2. Press the cargo box down onto the 2x2 deck studs.
3. Drop the rain tent over the box collar. The taper self-centres it.

### The kickstand

The kickstand foot is **coplanar with the underside of the frame**, not reaching the
ground. That is deliberate: it keeps the whole frame printable as one flat-bottomed piece
with no supports. The bike parks leaning about 16 degrees onto the stand, which is what a
real kickstand does anyway. Set `kickstand = false` for a clean silhouette and a bike
that lies down when released.

## Printing

Printer and filament defaults: see [docs/print-setup.md](../../docs/print-setup.md).

- Slicer profile: `0.20mm Balanced Strength @BBL H2D`
- Material: SUNLU PETG High Speed Matte
- Layer height / nozzle: 0.20 mm / 0.4 mm
- Infill / walls: 15% gyroid, 3 walls (the snap peg and the fork cheeks carry the load)
- Supports: **none** — every piece is modelled bottom-flat in print orientation
- Print plate (`part = "plate"`, the default): 220.6 x 95.8 x 52.6 mm, all five pieces
- Orientation: as exported. Frame stands upright on its beam; box sits floor-down; tent
  prints **roof-down**, opening up; wheels lie tread-down with the peg pointing up.

Print the pieces in different colours — the `plate` layout keeps them separate, or export
each one on its own with `-D 'part="..."'`.

## Tuning the fit

Clutch power and snap force are the things a render cannot tell you. After the first test
print:

| Symptom | Fix |
|---------|-----|
| Box is loose on the deck | Raise `stud_rescale` in 0.01 steps (1.02–1.04 is typical) |
| Box is too tight / will not seat | Lower `stud_rescale`, or lower `wall_splines_rescale` |
| Sockets bind on real DUPLO | `wall_splines_rescale = 0.3` — the LEGO.scad author notes this value for Bambu + PETG |
| Tent falls off the box | Raise `tent_grip` |
| Tent will not go on | Lower `tent_grip` |
| Wheel will not press into the dropout | Lower `dropout_pinch` or `dropout_neck_h` |
| Wheel drops back down the slot | Raise `dropout_pinch` |
| Wheel wobbles side to side | Lower `fork_gap` |
| Box fouls the handlebar | Raise `deck_x`, or lower `bar_x` |
| Box front does not clear the wheel | Lower `box_flare_front`, or raise `wheelbase` |
| Figure will not straddle the wall | Lower `rider_wall_t`, or `rider_wall_h` |
| Tent window edges sag | Lower `tent_window_w` — the flat bridge is `tent_window_w` minus twice the corner radius |
| Rider fouls the steering column | Raise `bar_x`/`deck_x`/`wheelbase`, or lower `rider_x` |
| Figure's feet will not reach the studs | Adjust `rider_z`; the stud spacing is fixed to the DUPLO pitch |
| Wheel wobbles on its axle | Lower `axle_hole_d` toward `axle_d` |
| Peg petals snapped on assembly | Raise `slot_depth` or lower `barb_d` |

## Export

```sh
# all five pieces, laid out on the bed
./scripts/export.sh projects/lego-duplo-bakfiets/lego-duplo-bakfiets.scad

# one piece at a time
./scripts/export.sh projects/lego-duplo-bakfiets/lego-duplo-bakfiets.scad 3mf -D 'part="frame"'
./scripts/export.sh projects/lego-duplo-bakfiets/lego-duplo-bakfiets.scad 3mf -D 'part="wheel"'
```

Set `part = "assembled"` in the OpenSCAD GUI to see the whole bike.

### MakerWorld version

**None.** This model needs [LEGO.scad](../../libs/README.md), which MakerWorld's
Parametric Model Maker does not bundle, so `scripts/makerworld.py` refuses it and there is
no `makerworld.json` here. See [docs/makerworld-parametric.md](../../docs/makerworld-parametric.md).
